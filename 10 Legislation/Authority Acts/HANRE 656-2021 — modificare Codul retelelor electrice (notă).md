# HANRE nr. 656/2021 — restructuring amendment to the Electricity Network Code — Analysis

**Raw text:** [[HANRE 656-2021 — modificare Codul retelelor electrice (text)]] ✅ *81 pp. amending act* · **Parent:** [[HANRE 423-2019 — Codul retelelor electrice (notă)]] *(decision-only annex still incomplete)* · **Connection:** [[HANRE 311-2026 — racordarea la retelele electrice (notă)]] · **Hub:** [[MOC — Racordare și acces la rețele]] · [[MOC — Energetică]]

> [!abstract] Executive summary & commercial impact
> **Core purpose:** Rebuilds HANRE 423/2019 into a five-part ENTSO-E-style network code (access/connection → operational security → operational planning → frequency-power & reserves → system balancing) and repeals the 2007 TSO/DSO technical norms (HANRE 266 & 267/2007).
> **Primary business risk:** Treating the vault’s 423 **decision-only** file as the operative code. For technical parameters, **this amending act is currently the richest in-vault substance** — but it is still not a clean consolidation, and later amendments (e.g. HANRE 646/2025 noted elsewhere) must be checked.

> [!warning] Completeness status after this ingest
> Parent annex of 423 remains missing as a standalone consolidation. HANRE 656 supplies large inserted operative text (Parts I–V + definitions). Advice on FRT, reserves (RSF/RRF/RI), (N-1), alert/emergency states should cite **656 + current legis consolidation**, not the 423 decision stub alone.

## 2. Architecture inserted into the Network Code

| Part | Title (as inserted) | Working content |
|---|---|---|
| **I** | Accesul și racordarea la rețelele electrice | Structural label after harmonisation clause; connection interface with connection regulation |
| **II** | Securitatea operațională | Operational security limits, contingencies, normal/alert states |
| **III** | Planificarea operațională | Outage / availability planning coherence |
| **IV** | Reglajul frecvență-putere și rezervele | FCR/FRR/RR-style reserve products (RSF, RRF, RI in MD drafting) |
| **V** | Asigurarea echilibrului sistemului | System balancing duties |

### Key definitional inserts (pct. 3 — non-exhaustive)
* **siguranța în funcționare** — ability to keep/return to normal state within security limits
* **restricție** — situation requiring a remedial measure
* **situație cu N / (N-1)**; **lista de contingențe**; **criteriul (N-1)**
* **stare normală / de alertă** (and related operational states in the inserted block)
* **furnizor de rezerve**, **unitate / grup de furnizare a rezervelor**
* **zonă RFP** (frequency-power control area); **durată de restabilire a frecvenței**

These are the vocabulary generators use when ANRE/TSO disputes turn on whether a plant “must stay connected”, whether a contingency list was correctly applied, or whether a reserve provider met product requirements.

## 3. Practical mechanics

### A. Generators & storage
* Fault-ride-through, frequency/voltage withstand and telemetry duties live in the network-code layer that 656 expands — cross-check against [[HANRE 311-2026 — racordarea la retelele electrice (notă)]] for the **connection procedure** vs **technical admission** split.
* Reserve-providing units/groups need contractual or legal obligation + common/multiple connection-point aggregation rules as defined.

### B. TSO (Moldelectrica) operational control
* (N-1) security, contingency lists, remedial measures and alert/emergency transitions are TSO-led; non-compliance → dispatch/disconnection risk under the code + market rules [[HANRE 283-2020 — Regulile pietei energiei electrice (notă)]].

### C. Legacy technical norms wiped
* Projects or grid studies still citing HANRE 266/267 (2007) are on repealed instruments — remap to 423 as amended by 656 (+ later amendments).

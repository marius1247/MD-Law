**de facturare netă până la data de 31 decembrie 2025**

|     |     |     |
| --- | --- | --- |
| **Cota de capacitate pentru implementarea mecanismului de facturare netă, MW** | **Categoria de consumatori** | **Plafoanele de capacitate individuale**, **kW** |
| 100 | Pentru instalațiile PV, instalațiile eoliene și pentru instalațiile de biogaz montate de către consumatorii casnici | Consumatorii casnici pot alege între:<br><br>un plafon de capacitate individuală care este mai mic sau egal cu 10 kW; sau<br><br>un plafon de capacitate individuală determinat conform formulei:<br><br>,<br><br>unde:<br><br>– plafonul de capacitate individuală calculat pentru consumatorul casnic respectiv;<br><br>– valoarea maximă a consumului anual din ultimii 3 ani calendaristici a consumatorului final de energie electrică;<br><br>– coeficientul ce exprimă energia electrică generată pe parcursul unui an calendaristic de o centrală electrică pentru producerea energiei electrice din surse regenerabile de energie cu puterea instalată de 1 kW, care pentru: o instalație PV este egală cu 1200 kWh/kW, pentru o instalație eoliană este egală cu 1600 kWh/kW, iar pentru o instalație de biogaz este egală cu 6100 kWh/kW |
| Pentru instalațiile PV, pentru instalațiile eoliene și pentru instalațiile de biogaz montate de către instituțiile bugetare finanțate din bugetul de stat sau din bugetele locale | Se determină individual pentru fiecare consumator final de energie electrică, conform formulei:<br><br>,<br><br>unde:<br><br>– plafonul de capacitate individuală calculat pentru consumatorul noncasnic respectiv;<br><br>– cea mai mare valoare dintre:<br><br>– valoarea maximă a consumului anual din ultimii 3 ani calendaristici a consumatorului noncasnic de energie electrică; și<br><br>– produsul dintre puterea contractată a locului de consum și consumul mediu anual pentru 1 kW al consumatorilor din categoria din care face parte consumatorul noncasnic de energie electrică pentru care se calculează plafonul de capacitate individuală, determinat pentru zona de activitate a operatorului sistemului de distribuție la care este/urmează a fi racordată centrala electrică a consumatorului noncasnic respectiv;<br><br>– coeficient ce exprimă energia electrică generată pe parcursul unui an calendaristic de o instalație PV cu puterea instalată de 1 kW, care pentru: o instalație PV este egală cu 1200 kWh/kW, pentru o instalație eoliană este egală cu 1600 kWh/kW, iar pentru o instalație de biogaz este egală cu 6100 kWh/kW. |

# Biofuels / biomass fuels — regulatory briefs

Step 6 for [[MOC — Biocarburanți și combustibili din biomasă]]. Frame: [[Legea 10-2016 — surse regenerabile (notă)|L10/2016]] · Sustainability: [[HG 53-2025 — durabilitate biocarburanti emisii GES (notă)|HG 53/2025]] · Stats: [[HG 74-2025 — calcul consum energie regenerabila (notă)|HG 74]] · Petroleum channel: [[Legea 461-2001 — piata produselor petroliere (notă)|L461]].

---

## A. Segment briefs

### 1. Transport RES accounting

| | |
|---|---|
| **What** | National share of RES in final transport energy; category sub-shares in PNIEC |
| **Who** | Government (PNIEC) · CNED / ministry reporting · EnC monitoring |
| **Key rules** | L10 arts. 6–8, **26⁷(1)** categories (a)–(d) · HG 74 calculation |
| **Practice** | PNIEC targets ~**6.9%** RES in transport by 2030 (modelling). Electrification is the long path; biofuels are the near-term compliance tool. Volumes that fail sustainability **do not count**. |

### 2. Sustainability & GHG criteria

| | |
|---|---|
| **What** | Land-use / biodiversity / forest criteria + minimum GHG savings so energy *counts* |
| **Who** | Producers · Environment Agency · voluntary schemes |
| **Key rules** | L10 art. **26¹** · [[HG 53-2025 — durabilitate biocarburanti emisii GES (notă)\|HG 53]] regulation + GHG methodology · [[Concept — Criterii de durabilitate biocarburanți]] |
| **Practice** | HG 53 IF ≈ **11.02.2026** (12 months after MO 11.02.2025). Abrogates HG 107/2019. Advise post-IF from HG 53 only. |

### 3. Mass balance & verification

| | |
|---|---|
| **What** | Chain-of-custody so mixed batches keep sustainability/GHG attributes; single counting |
| **Who** | Biofuel producers · independent assessors · Environment Agency |
| **Key rules** | Art. **26²(3)–(7)** · HG 53 verification chapter |
| **Practice** | Annual independent assessment of Environment Agency filings. State-aid flags on batches (art. 26²(3)(f)). Geographic origin of biomass irrelevant to duty (art. 26²(6)). |

### 4. Advanced / capped / high-ILUC feedstocks

| | |
|---|---|
| **What** | Classification that drives double-counting, caps, and exclusions |
| **Who** | Producers · importers claiming contribution |
| **Key rules** | HG 53 Annex 2 §1 advanced · §2 capped (UCO; cat. 1–2 animal fats under L129/2019) · Annex 3 high/low ILUC · art. 26⁷(1) |
| **Practice** | **Primary business risk** from HG 53 note: mis-scoring advanced vs capped streams. High-ILUC food/feed expansion into high-carbon stock land excluded unless low-ILUC-risk certified. |

### 5. Importer blending / purchase obligation

| | |
|---|---|
| **What** | Duty on main petroleum importers to place fuels with min biofuel shares / quantities |
| **Who** | L461-licensed **importatori** |
| **Key rules** | Arts. 14(1)(e), **29(3)**, 26⁷(3)(a)–(b) · ANRE annual quantities by market share |
| **Practice** | **Local producers first**; shortfall from import (pre-blended or for blending). Breach → ANRE fine up to **5%** of annual revenue from main petroleum products. Info duties art. 8(6)–(7) → up to **1%**. Retail price still under [[Concept — Preț maxim ANRE produse petroliere]]. |

### 6. Local production & blending plants

| | |
|---|---|
| **What** | Domestic biofuel production and industrial blending installations |
| **Who** | Producers · blending plant operators |
| **Key rules** | Art. **25(3)** prior **notification** to ANRE → registers art. 14(1)(b³)–(b⁴) |
| **Practice** | Notification/register = **monitoring**, not a licence condition precedent. Quality of biofuel purchased by importers must meet sustainability/GHG criteria (art. 25(1)). |

### 7. Ceiling prices for local biofuels

| | |
|---|---|
| **What** | ANRE *prețuri plafon* for local biofuels by art. 26⁷(1) category, referenced to EU market prices |
| **Who** | ANRE · local producers · obligated importers |
| **Key rules** | Art. 14(1)(g¹) · art. 14(4) (differential vs imported main products enters petroleum price formation) |
| **Practice** | Ceiling prices discipline the purchase obligation economics — not a retail pump price. Pump max remains L461 art. 4. |

### 8. Biomass fuels in heat / power (counting gates)

| | |
|---|---|
| **What** | When solid/gaseous biomass energy counts toward L10 art. 26¹(2) purposes |
| **Who** | Heat/power plant operators using biomass fuels |
| **Key rules** | Art. 26¹(4): criteria bind if thermal ≥ **20 MW** (solid) or ≥ **2 MW** (gaseous biomass gas); electricity further HE-CHP / BAT / 36% net efficiency / BECCS gates (5)–(6) |
| **Practice** | Cross-link [[MOC — Piața energiei termice]] / [[Concept — Cogenerare de înaltă eficiență]] when CHP claims RES credit from biomass. |

### 9. RFNBO bridge (not a biofuel segment)

| | |
|---|---|
| **What** | Renewable fuels of non-biological origin in transport (incl. renewable H₂ pathways) |
| **Key rules** | HG 53 **pct. 2**: ≥ **70%** GHG reduction from **1 Jan 2026** · Annex 1 energy content includes renewable H₂ |
| **Practice** | → [[Energetică — hidrogen gap stub (notă)]]. Do not treat RFNBO as covered by biofuel feedstock annexes. |

## B. What this layer is *not*

| Not this | Where it lives instead |
|---|---|
| Organised DA/ID / PVT | Electricity / gas hubs |
| Petroleum import/retail licensing & daily max price | [[MOC — Piața produselor petroliere]] |
| Dedicated hydrogen market / network code | [[Energetică — hidrogen gap stub (notă)]] |
| Electricity RES fixed tariff / auctions | L10 eligible-producer track · FCEE |
| Geothermal / coal markets | Existing stubs |

## C. Practitioner checklist

- [ ] Identify whether the client is **importer**, **producer**, **blender**, or **heat/power biomass user**
- [ ] Pull current ANRE annual min quantities / ceiling prices
- [ ] Map feedstock to HG 53 Annex 2 section (and Annex 3 if food/feed ILUC risk)
- [ ] Confirm voluntary-scheme certificate / mass-balance pack before claiming counting
- [ ] Separate L461 retail max-price compliance from L10 blending duty
- [ ] After HG 53 IF: retire HG 107/2019 methodology citations
- [ ] RFNBO / H₂ volumes → hydrogen stub + 70% floor from 1 Jan 2026

# Petroleum products market segments — regulatory briefs

Step 4 for [[MOC — Piața produselor petroliere]]. Frame: [[Legea 461-2001 — piata produselor petroliere (notă)|L461/2001]] · Crisis patch: [[Legea 101-2026 — consolidarea mecanismelor de interventie in situatii de criza (notă)|L101/2026]] · Crisis frame: [[Legea 248-2025 — managementul situatiilor de criza (notă)|L248]].

---

## A. Segment briefs

### 1. Import

| | |
|---|---|
| **What** | Entry of petroleum products into free circulation after customs clearance |
| **Who** | Licensed **importator** |
| **Key rules** | Art. 18 (L101 rewrite): only through **Government-designated** customs posts / modalities; after free circulation, movement to depots/stations under accompanying documents and accounting rules |
| **Practice** | Wrong post / missing paperwork = customs + licence exposure. Import is the strategic choke point — Moldova has no refining at scale (PNIEC). |

### 2. Transport

| | |
|---|---|
| **What** | Movement of products with specialised means |
| **Who** | Economic operator with specialised vehicles; importer may transport if separate primary/accounting unit (art. 13) |
| **Practice** | Logistics licence conditions and industrial-safety registration for hazardous objects (art. 14(4)). |

### 3. Storage / depots

| | |
|---|---|
| **What** | Holding current stocks in certified petroleum depots / stations |
| **Who** | Importers / depositaries |
| **Key rules** | Art. 14 special conditions: ≥ **1000 m³** main products or ≥ **150 m³** LPG (own or leased); storage only in certified facilities (art. 13(3)); Ch. V |
| **Practice** | Minimum storage is an **energy-security licence gate**, not optional working capital. Distinct from state material reserves. |

### 4. Wholesale

| | |
|---|---|
| **What** | Comercializare cu ridicata |
| **Who** | Licensed importer (art. 13(1)(a)) and other licensed participants per art. 12 classes |
| **Practice** | No ANRE daily max-price on wholesale in the same art. 4 form — the hard ceiling is **retail**. Wholesale still sits inside the licence perimeter and quality duties. |

### 5. Retail (filling stations) — commercial core

| | |
|---|---|
| **What** | Comercializare cu amănuntul at certified stations |
| **Who** | Licensed retailers / importers with retail rights |
| **Key rules** | [[Concept — Preț maxim ANRE produse petroliere]] — daily ANRE max for **standard-type main products**; ban on over-max sales (art. 4(4)); no mixing grades in same tank (art. 13(4)); certified station required (art. 14(2), 26) |
| **Practice** | Diary ANRE publication every working day. Excise/VAT/margin components → [[Concept — Accize]] · [[Concept — TVA]]. |

### 6. LPG track

| | |
|---|---|
| **What** | Parallel market for liquefied gas at filling stations |
| **Who** | Holders of art. 12(b) licence |
| **Key rules** | Same architecture; lower minimum depot (150 m³); retail certification still required |
| **Practice** | Do not assume petrol/diesel licence covers LPG — separate class. |

### 7. Crisis mode

| | |
|---|---|
| **What** | [[Concept — Situație de criză în domeniul petrolier]] + L248 alert/emergency |
| **Who** | Market participants · CNMC · ANRE |
| **Key rules** | Stock-out: non-standard main types may sell ≤ standard max (art. 4(2)); CNMC may temporarily derogate from art. 4 / Annex 2 (art. 6(7)) |
| **Practice** | **Decision tree:** (1) Is petroleum crisis / L248 alert-emergency live? If **no** → ordinary daily max binds. (2) Are standard-type stocks exhausted? If **yes** → non-standard may sell **only ≤** standard max (art. 4(2)) — still a ceiling. (3) Has **CNMC** issued an art. 6(7) derogation? If **no** → do not invent price freedom. (4) Keep this playbook **separate** from electricity [[Concept — Situație excepțională electroenergetică]] / HG 820. |

## D. Professional deepening — licence & formula traps

| Trap | Rule |
|---|---|
| Petrol/diesel licence covers LPG | **No** — art. 12(a) vs 12(b) |
| Depot minima are “optional working capital” | **No** — art. 14 security gates (1000 m³ / 150 m³) |
| Wholesale also has daily ANRE max like retail | **Not** in the same art. 4 form — hard ceiling is **retail**; wholesale still inside licence + quality perimeter |
| Invent Annex 2 components from vault OCR | **No** — legis.md / ANRE methodology PDF only |
| Price-cap compliance = full retail compliance | **No** — ISS quality (art. 5) is a separate exposure |
| *Plată regulatorie* | Annual regulatory payment on **importers** (art. 2) — budget for it in licence economics |

Crisis tree → segment §7. Concept → [[Concept — Preț maxim ANRE produse petroliere]].

# Concept — Garanție de bună execuție a avizului de racordare

**RO:** garanție financiară de bună execuție a avizului de racordare · **EN:** connection-notice performance guarantee

> Distinct from the **public-procurement** performance bond — see [[Concept — Garanție de bună execuție]].

## Definition
Financial security that the holder of a connection notice (*aviz de racordare*) for a power plant **above 200 kW** must lodge with the system operator so that reserved grid capacity is backed by a real project. Introduced by [[Legea 45-2025 — garantiile avizelor de racordare si tolerante dezechilibre (text)|LP45/2025]] (L107 art. 47(9)–(13)); operationalised under [[HANRE 311-2026 — racordarea la retelele electrice (text)|HANRE 311/2026]] and ANRE’s guarantee instruction.

## How it works
1. **Trigger:** *aviz* for plant **> 200 kW** (HANRE 311 also extends analogous logic to large storage).
2. **Deposit** with the SO after the *aviz* is issued; quantum / form / deadlines = **ANRE**.
3. **Non-deposit → cancellation** of the *aviz* by the SO, with notification.
4. **Exemptions:** plants that already hold **eligible-producer** status; **renewable energy communities**.
5. **Refund:** if guarantee was posted before eligible-producer status, return **on request** once status is granted.
6. **Legacy squeeze (LP45 Art. III):** existing avisuri only need the guarantee on **extension**; voluntary surrender until **30.06.2025**; otherwise **taxă de nevalorificare 50–70%** of the guarantee equivalent at expiry → state budget / SFS.

## Notes / conclusions
> Capacity hoarding tool: the guarantee + nevalorificare tax force developers to build, extend properly, or release the queue. Always read the live ANRE instruction for the MDL/kW figure before advising hold vs surrender.
